# 📱 Social Media Well-being Predictor

A Machine Learning web application that predicts a user's social media well-being category based on their social media usage habits and lifestyle factors.

🌐 Live Demo:

https://st9jkfc7fwrufef78ctg4s.streamlit.app/

---

## ✨ Features
*Predicts overall well-being as:
 
  *😊 Good
 
  *😐 Moderate
  
  *⚠️ At Risk
     
*Clean and interactive Streamlit interface
 
*User-friendly dropdowns and input fields
 
*Real-time prediction
 
*Machine Learning powered 





---

## 🛠️ Tech Stack
*Python
 
*Streamlit
 
*Scikit-learn
 
 
*Pandas
 
 
*NumPy
 

*Joblib
 
 

---

## 📊 Dataset
The model is trained on a social media usage and mental well-being dataset containing features such as:

*Age
 
*Gender
 
*Occupation
 
*Most Used Platform
 
*Number of Platforms Used
 
*Daily Screen Time
 
*Night-time Usage
 
*Primary Purpose of Social Media
 
*Average Sleep Hours
 
*Anxiety Score
 
*Low Mood Score
 
*Life Satisfaction
 
*Loneliness
 
*Self-esteem
 
*Fear of Missing Out (FOMO)
 
*Social Comparison
 
*Physical Activity
 
*Screen Time Limits
 
*Digital Detox Attempts
 
*Mental Health Support

 ---
 
## 🧠 Machine Learning Model
* Algorithm: K-Nearest Neighbors (KNN) Classifier
  
* Data preprocessing using categorical encoding

* Model serialization using Joblib
   
* Interactive prediction through Streamlit
